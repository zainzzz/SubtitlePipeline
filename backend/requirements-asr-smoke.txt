# ASR-enabled smoke build. Like requirements-smoke.txt but adds ONE real

# exercise the actual transcription pipeline on a known fixture

# - It's the smallest ML dep in the project (ctranslate2 + tokenizers;

# - Works on aarch64 (Apple Silicon) without torch / GPU.
# - Gives us a real Chinese transcription result in <30s on a short clip.
#
# Used by scripts/docker-smoke-asr.sh to validate that the full pipeline
# (extract_audio → run_asr → align_segments → text_process → translate →
# subtitle_render → output_finalize → quality_checker) actually produces a
# usable .srt with correct Chinese characters. NOT used in production.
