# Triage Labels

## Label vocabulary

| Label | Meaning |
|---|---|
| `needs-triage` | Maintainer needs to evaluate |
| `needs-info` | Waiting on reporter for more info |
| `ready-for-agent` | Fully specified, AFK-ready — agent can pick it up with no human context |
| `ready-for-human` | Needs human implementation |
| `wontfix` | Will not be actioned |

## Display names (informational only)

These are shown in skill output; the canonical label is the English key above:

| Label | 中文展示 |
|---|---|
| `needs-triage` | 需分类 |
| `needs-info` | 等待信息 |
| `ready-for-agent` | 可移交 |
